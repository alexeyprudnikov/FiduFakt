# FiduFakt

## Hochperformantes Invoicing-as-a-Service (B2B SaaS)

### Automatisierte, rechtskonforme Rechnungsstellung via API für Entwickler und Unternehmen.

***Das Problem:*** Rechnungsstellung in modernen Web-Apps ist fehleranfällig. Die Generierung von PDFs blockiert die Serverleistung (hohe Latenz), und gesetzliche Vorgaben wie elektronische Rechnungen (ZUGFeRD / XRechnung) sind komplex zu implementieren.

***Die Lösung (FiduFakt):*** Eine ultraschnelle REST-API, die strukturierte Rohdaten (JSON) empfängt, sofort mit einem 202 Accepted antwortet und die schwere Dokumentenverarbeitung asynchron im Hintergrund erledigt.

### Kernfunktionen & Features

- **Automatisierte Erstellung:** Vollwertige PDFs inklusive eingebetteter, gesetzeskonformer XML-Rechnungsmetadaten.

- **Echtzeit-Dashboard:** Ein modernes Kunden-Interface für Unternehmen zur Übersicht aller Finanzen, Live-Aktivitäten und zum direkten PDF-Download.

- **API-Key & Quota-Management:** Monetarisierung über ein flexibles Subscription-Modell mit automatisierten Kontingent-Limits (Quotas) und intelligenter UI-Sperre bei Erreichen des Paketlimits.
